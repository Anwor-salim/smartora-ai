# سمارتورا AI - منصة أتمتة الرد الآلي بالذكاء الاصطناعي عبر الواتساب
### SmartOra AI - Multi-Tenant WhatsApp AI Auto-Responder SaaS

نظام متكامل ومتقدم مبني باستخدام **Laravel 12** و **Filament PHP 3** يتيح للشركات والمتاجر والمؤسسات أتمتة خدمة العملاء والرد الآلي الذكي عبر الواتساب على مدار الساعة دون تدخل بشري، مع ربط وتحليل ملفات الأسعار والكتالوجات (Excel و CSV و PDF) وتقديم لوحات تحكم عصرية تدعم اللغة العربية بالكامل (RTL).

---

## 🌟 أبرز الميزات (Key Features)

- **بوابة الإدارة العليا (Super Admin Panel):**
  - إدارة الشركات والمشتركين وحالات الاشتراكات.
  - مراقبة رسائل ومحادثات العملاء لحظياً.
  - محاكي ذكاء اصطناعي عام للاختبار والتحكم.
  - إحصائيات دقيقة وإشعارات فورية.

- **بوابة الشركات والمنشآت (Company Portal):**
  - ملف تعريفي كامل بالمنشأة وساعات العمل والموقع مع رابط خرائط جوجل.
  - **قاعدة المعرفة الذكية (Knowledge Base):** رفع ملفات المنتجات والأسعار وقوائم الخدمات (Excel .xlsx / CSV / PDF) واستخراج الأصناف والجداول تلقائياً.
  - **ربط الواتساب (WhatsApp Connection):** ربط فوري عبر مسح كود الاستجابة السريعة (QR Code).
  - **محاكي محادثات الواتساب التفاعلي:** تجربة الردود والتأكد من دقة الذكاء الاصطناعي قبل النشر الفعلي.
  - أرقام مسؤولي الرد الأولي والتحويل التلقائي للدعم البشري.

- **محرك الذكاء الاصطناعي الهجين (AI Engine):**
  - دعم الربط المباشر مع Google Gemini API أو OpenAI.
  - محرك محلي فائق السرعة يعتمد على مطابقة النصوص واستخراج الجداول وقراءة سياق الملفات بدون أي انقطاع.

## 🛠 المتطلبات والتشغيل (Quick Start)

### المتطلبات:
- PHP >= 8.2 (مع تفعيل إضافات: `pdo_sqlite` أو `pdo_mysql`, `zip`, `mbstring`, `fileinfo`)
- Composer
- Node.js & NPM

### خطوات التشغيل:
```bash
# 1. التوجه لمجلد الباك إند
cd backend

# 2. تثبيت الحزم
composer install

# 3. إعداد ملف البيئة وقاعدة البيانات
cp .env.example .env
php artisan key:generate
php artisan migrate --seed

# 4. تشغيل السيرفر
php -S 0.0.0.0:8088 -t public server.php
```
